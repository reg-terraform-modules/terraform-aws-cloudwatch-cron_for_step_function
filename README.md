# cloudwatch-cron_for_step_function

This module generates a cron job for invoking Step functions at given times/intervals.

## Module description
Generates the cron job as an event rule in Cloudwatch, and connects a Step function to an event target. Requires that permission for invoking Step function is set up in IAM.
